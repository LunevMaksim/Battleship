# 🚢 Battleship (Морской бой) — ООП Архитектура

Консольное приложение «Морской бой», разработанное на **Java 21** с применением принципов чистой архитектуры (Clean Architecture), строгим разделением логики и консольного вывода, а также поддержкой воспроизводимости партий.

## 🛠 Технологии
* **Язык:** Java 21
* **Система сборки:** Apache Maven
* **Тестирование:** JUnit 6 

## 📐 Архитектура проекта
Проект разделен на следующие пакеты:
* `org.battleship.model` — чистые доменные модели (`Board`, `Cell`, `Player`, `PlayerKnowledge`, `State`, `Coordinate`). Не содержат логики вывода в консоль.
* `org.battleship.player` — сущности игроков (`ConsolePlayer`, абстрактный класс `Player`).
* `org.battleship.service` — сервисный слой (`GameEngine`, `PlacementValidator`, `BoardPrinter`, `GameSettings`). Отвечает за правила, валидацию, отрисовку и игровой цикл.

## 🌟 Особенности реализации
1. **Разделение правил и вывода:** Вся визуализация инкапсулирована в сервисе `BoardPrinter`. Модели не используют `System.out.println`.
2. **Воспроизводимость партий:** Инициализация генератора случайных чисел (`Random`) через `GameSettings` по заданному `seed` гарантирует одинаковый ход симуляции при повторных запусках.
3. **Бонусная механика:** У каждого игрока есть одна мина для удара по площади **3х3** клетки.

## 🚀 Как запустить проект

1. Сборка проекта

Убедитесь, что у вас установлен Maven, и выполните в корне проекта команду для сборки:
```
mvn clean compile
```
2. Запуск тестов (JUnit 5)

Для запуска полного набора тестов (более 20 сценариев, граничные случаи и проверка исключений):
```
mvn test
```
3. Запуск приложения

Вы можете запустить игру через вашу среду разработки (например, открыв класс org.battleship.Main в IntelliJ IDEA и нажав ▶️) или через терминал с помощью Maven:
```
mvn exec:java -Dexec.mainClass="org.battleship.Main"
```
